# hypeagent

Standalone CLI for running LLM-powered persona agents against social platforms.

## Quick start

```bash
pip install -e ".[dev]"
hypeagent version
hypeagent validate --config examples/reddit/hypeagent.yaml --secrets examples/reddit/secrets.example.yaml
```

See [docs/implementation_plan.md](docs/implementation_plan.md) for the full build specification.
